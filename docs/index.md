## How this is organized

Each topic folder has its own `index.md` overview plus one page per subtopic.
Pages use admonitions for callouts and fenced Mermaid blocks for diagrams —
no external image tool needed for most diagrams. See the root `README.md`
for how to add a new topic or page.

!!! tip "This is a living document"
    Notes here are meant to be edited in place as understanding improves —
    prefer updating an existing page over letting two pages drift out of
    sync on the same subject.
